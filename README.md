# 📊 Enterprise E-Commerce Analytics Dashboard

An executive-ready, AI-driven E-Commerce Intelligence Dashboard designed to replace spreadsheet dependencies with high-performance analytics pipelines and generative insights.

Built with **Streamlit**, **DuckDB**, **Polars**, **Plotly**, and powered by **Google Gemini 3.6 Flash**.

---

## 🚀 Key Features

* **High-Performance In-Memory Engine:** Utilizes **DuckDB** and **Polars** to query and process hundreds of thousands of transaction records in sub-seconds.
* **Strict Schema Validation:** Enforces data integrity using **Pydantic** models before passing datasets to the frontend.
* **10 Strategic Business Modules:**
  1. **Unit Economics & Margins:** Subcategory gross revenue, net margin %, and profitability analysis.
  2. **Customer LTV : CAC Ratio:** Segment-level health metrics evaluating customer acquisition payback.
  3. **RFM Segmentation (Top VIPs):** Identifies high-value customers alongside their primary preferred product category for targeted CRM.
  4. **Cohort Retention Analysis:** Visualizes customer retention across multiple acquisition cohorts using an interactive Heatmap matrix.
  5. **Promotion Leakage Audit:** Multi-dimensional Bubble Chart correlating discount depth against gross revenue leakage.
  6. **Logistics SLA & Delivery:** Tracks delivery delays and warehouse performance bottlenecks.
  7. **Returns Root Cause Analysis:** Donut Chart breaking down the financial impact of customer return reasons.
  8. **Multi-Channel Attribution (ROAS):** Evaluates Return on Ad Spend per acquisition channel.
  9. **Supplier Velocity Scorecard:** Evaluates vendor product turnover velocity against margin contribution.
  10. **VoC Sentiment Correlation:** Correlates customer sentiment ratings with bottom-line profitability.
* **Executive MD&A Generation:** Automated 3-bullet Management Discussion & Analysis (Key Observation, Business Impact, Strategic Action) generated by **Gemini 3.6 Flash**.
* **Bilingual Chat with Data:** Real-time conversational interface supporting both English and Thai to query active business views dynamically.
* **Print-to-PDF Ready:** Built-in `@media print` CSS engine optimized for executive boardroom exports (`Ctrl + P`).

---

## 🛠️ Tech Stack

* **Frontend:** [Streamlit](https://streamlit.io/)
* **Visualization:** [Plotly Express](https://plotly.com/python/)
* **Data Processing:** [DuckDB](https://duckdb.org/) & [Polars](https://pola.rs/)
* **Schema Validation:** [Pydantic v2](https://docs.pydantic.dev/)
* **Generative AI:** Google Generative AI (`gemini-3.6-flash`)
